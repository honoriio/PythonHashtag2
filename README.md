# PythonHashtag2

Repositório de estudos em Python criado para registrar minha evolução prática durante o aprendizado da linguagem e de bibliotecas voltadas para análise de dados.

## Sobre o repositório

Este repositório reúne exercícios, testes e exemplos desenvolvidos ao longo dos meus estudos em Python.  
O objetivo é consolidar fundamentos da linguagem e ampliar o conhecimento em bibliotecas e ferramentas usadas no ecossistema Python.

Ao longo do repositório, há conteúdos relacionados a:

- fundamentos da linguagem
- funções
- list comprehension
- tratamento de erros com `raise` e `assert`
- NumPy
- Pandas
- SQL
- exercícios aplicados com análise e manipulação de dados
- pequenos estudos práticos, como previsão e relatórios de vendas

## Objetivo

Este repositório não foi criado como um projeto final, mas como um ambiente de prática e aprendizado.  
Ele representa uma etapa importante da minha jornada em programação, mostrando minha evolução desde os fundamentos até conteúdos mais avançados dentro do Python.

## Estrutura

O repositório está organizado em temas de estudo, incluindo:

- `Exercicios Fundamentais`
- `Functions`
- `List compreheision`
- `Numpy`
- `Pandas`
- `Sql`
- `Previsão de vendas`
- `Relatorio de Vendas`
- `Segmentação de clientes`

## Tecnologias utilizadas

- Python
- NumPy
- Pandas
- SQLite / SQL

## Observações

Por se tratar de um repositório de estudos, alguns arquivos refletem diferentes fases do meu aprendizado e podem variar em complexidade.  
A proposta é manter esse material como registro da minha evolução prática com Python.
